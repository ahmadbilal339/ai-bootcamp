# Week 3 – Data Preprocessing, Feature Engineering & Exploratory Data Analysis

> Learning how to prepare real-world datasets for Machine Learning through data preprocessing, feature engineering, visualization, and statistical analysis.

---

# 📖 Overview

Week 3 focused on one of the most critical stages of every Machine Learning project—**data preprocessing**. Raw datasets are rarely ready for model training, so this week emphasized cleaning, transforming, and understanding data before applying machine learning algorithms.

Through hands-on labs, I explored techniques for handling missing values, encoding categorical variables, feature engineering, scaling, outlier detection, and exploratory data analysis (EDA). These skills form the foundation for building reliable and high-performing machine learning models.

---

# 🎯 Learning Objectives

- Understand the Machine Learning preprocessing pipeline.
- Clean and prepare real-world datasets.
- Handle missing and inconsistent data.
- Perform feature engineering.
- Detect and treat outliers.
- Scale and normalize numerical features.
- Explore datasets through visualization.
- Select relevant features for machine learning.
