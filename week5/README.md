# Week 5 – Deep Learning with TensorFlow & PyTorch

> Building intelligent systems using Deep Learning by understanding neural networks, training models, leveraging GPU acceleration, and exploring modern AI frameworks.

---

# 📖 Overview

Week 5 introduced the fundamentals of **Deep Learning**, a subset of Machine Learning that enables computers to learn complex patterns from data using artificial neural networks.

Throughout this week, I explored the complete deep learning workflow, from understanding neurons and activation functions to training neural networks using **TensorFlow** and **PyTorch**. Practical exercises also covered GPU acceleration, image classification, and an introduction to AutoML for automating machine learning workflows.

This week marks an important milestone in my AI learning journey by transitioning from traditional Machine Learning algorithms to modern Deep Learning techniques.

- Develop and train models using PyTorch.

- Explore AutoML concepts for automated model development.
