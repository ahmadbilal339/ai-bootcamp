# Week 1 – Python Fundamentals & Data Analysis

## 📖 Overview

Week 1 focused on establishing the core programming skills required for Artificial Intelligence and Machine Learning. The labs introduced Python fundamentals, numerical computing with NumPy, and basic data analysis techniques using real-world datasets.
