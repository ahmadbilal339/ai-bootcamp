# 🚀 Getting Started

Clone the repository:

```bash
git clone https://github.com/your-username/ai-bootcamp.git
```

Navigate to the project:

```bash
cd ai-bootcamp
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Launch Jupyter Notebook:

```bash
jupyter notebook
```
