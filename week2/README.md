# Week 2 – Data Analysis with Pandas & REST API Development

> Strengthening data manipulation skills with Pandas while building RESTful APIs using FastAPI.

---

# 📖 Overview

Week 2 expanded on the Python foundations established in Week 1 by introducing data manipulation with **Pandas** and backend API development using **FastAPI**. This week combined data analysis with software engineering practices, providing hands-on experience in processing datasets and building a fully functional REST API.

By the end of this week, I was able to clean and transform datasets, perform exploratory analysis, and develop a CRUD-based web API using FastAPI.

---

# 🎯 Learning Objectives

- Learn data manipulation using Pandas.
- Perform data cleaning and transformation.
- Analyze structured datasets.
- Understand REST API architecture.
- Build CRUD APIs using FastAPI.
- Work with request validation using Pydantic.
- Test APIs using Swagger UI.
